## 1. NVIDIA Nemotron-Cascade 2: 30B MoE로 구현한 고밀도 추론

NVIDIA가 Nemotron-Cascade 2를 공개했다. 총 30B 파라미터의 Mixture-of-Experts 모델이지만, 실제 추론 시 활성화되는 파라미터는 단 3B — 전체의 10%에 불과하다. 그럼에도 벤치마크 성능은 Qwen2.5-35B-A3B를 능가하고, Nemotron-3 Super 120B와 대등한 수준의 추론 밀도를 달성했다. 이것이 가능했던 핵심은 Cascade RL이라는 새로운 사후 학습 기법이다. 256K의 긴 컨텍스트와 함께 Python 추론 트레이스 1.9M 및 도구 호출 데이터를 활용해 에이전틱 능력을 극대화했다. 가중치는 Hugging Face를 통해 공개됐고, 로컬 LLM 커뮤니티에서 "작지만 강력한 추론 모델"로 즉각적인 주목을 받고 있다.

**Why it matters:** 30B 규모 모델이 120B급 추론 밀도를 낸다는 것은, 고성능 에이전트를 돌리기 위해 반드시 거대 인프라가 필요하다는 전제를 허문다. 저사양 기기에서도 복잡한 에이전트 작업이 가능해진다는 뜻이고, 이는 클라우드 API 의존도를 낮추고 로컬·온프렘 배포를 현실화하는 방향이다. 모델 크기와 성능 사이의 비선형 관계가 MoE 구조와 사후 학습의 조합으로 어디까지 확장되는지, 이 모델이 하나의 데이터 포인트를 제공한다.

- Cascade RL: 256K 컨텍스트, Python 추론 트레이스 1.9M, 도구 호출 데이터를 활용해 에이전틱 능력을 극대화했다.
- 가중치는 Hugging Face에 공개됐고, Apache 라이선스가 아닌 NVIDIA Open Model License 조건이다.

**What's next:** 활성 파라미터 3B로 120B급 추론 밀도를 냈다는 수치는, MoE 기반 고밀도 모델 경쟁을 촉발할 가능성이 높다. 다음 질문은 이 방향이 에이전틱 벤치마크 이외의 도메인에서도 유지되는지다.

NVIDIA가 자원 효율성의 한계를 끌어올리는 동안, 다른 방향의 실험도 진행됐다.

## 2. MiniMax M2.7: 스스로 진화하는 에이전트 모델의 첫걸음

중국의 MiniMax가 자가 개선 능력을 갖춘 M2.7 모델을 발표했다. 이 모델의 핵심은 Interleaved Thinking — 추론과 행동을 정교하게 엮어내는 기법이다. OpenClaw 벤치마크에서 100단계 이상의 추론을 수행하며 기존 대비 약 30%의 성능 향상을 기록했고, SWE-Pro에서 56.22%를 달성해 Claude 3.5 Opus와 대등하거나 이를 넘어서는 코딩·에이전트 성능을 보여줬다. 단순 텍스트 생성을 넘어 터미널 제어, 도구 사용 등 실제 작업 수행 능력에서도 높은 점수를 받았다.

"자율 진화"라는 표현이 과장처럼 들릴 수 있지만, 수치는 구체적이다. 모델이 복잡한 추론 과정에서 스스로 피드백을 주고받으며 성능을 높인다는 개념이, 100단계 추론과 30% 향상이라는 측정값으로 뒷받침되고 있다. 인간 라벨러의 개입 없이 모델 자신의 추론 흔적이 다음 학습의 재료가 된다는 구조다.

**Why it matters:** 모델이 자신의 추론 흔적에서 학습한다는 것은, 인간이 매번 피드백을 주지 않아도 시스템이 수렴한다는 가능성을 열어준다. SWE-Pro 56.22%라는 코딩 벤치마크 수치가 설득력을 높인다. 에이전트가 장기 작업을 수행하면서 스스로 실수를 교정할 수 있다면, 자율 실행의 신뢰도 임계값이 달라진다.

- 100단계 이상의 추론: 기존 에이전트 모델이 처리하기 어려웠던 장기 의존성 태스크를 다룬다.
- SWE-Pro 56.22%: Claude 3.5 Opus와 대등하거나 이를 넘어서는 코딩·에이전트 성능이다.

고밀도와 자율 진화 다음으로, 아키텍처 레벨에서 더 근본적인 도전이 등장했다.

## 3. Mamba-3: 트랜스포머를 앞지른 차세대 SSM

Together AI, CMU, Princeton이 협력해 Mamba-3를 공개했다. 트랜스포머 아키텍처의 한계를 극복하기 위한 SSM(State Space Model) 기반 모델로, 동일 조건에서 트랜스포머 기반 모델보다 벤치마크 점수가 약 4% 높으면서도 추론 속도는 최대 7배 빠르다. 핵심 기술은 두 가지다. MIMO(Multi-Input Multi-Output) SSM과 지수-사다리꼴(exponential-trapezoidal) 커널을 도입해 시퀀스 모델링의 효율성을 극대화했다. 아키텍처와 가중치 모두 완전 공개됐다.

트랜스포머는 시퀀스 길이가 늘어날수록 연산량이 제곱으로 증가하는 구조적 한계가 있다. SSM은 이를 선형 복잡도로 처리한다. Mamba-3는 그 위에 성능까지 앞선다는 데이터를 추가했다. 학계 세 기관의 협력 결과를 완전 오픈소스로 공개한 것도, 트랜스포머 중심의 현재 생태계에 대안을 제시하는 방식으로 읽힌다.

**Why it matters:** 트랜스포머가 현재의 지배적 아키텍처가 된 건 성능 때문이었다. Mamba-3는 성능도 앞서면서 속도는 7배라는 수치를 제시했다. 속도와 자원 효율이 함께 올라간다는 것은, 긴 컨텍스트를 실시간으로 처리해야 하는 에이전트 워크로드에서 특히 의미 있다. SSM이 트랜스포머를 대체할지는 아직 열린 질문이지만, 이번 발표로 그 가능성이 처음으로 수치로 뒷받침됐다.

**What's next:** SSM 기반의 고속 추론은 수많은 에이전트가 동시에 협업하는 워크로드의 병목을 제거할 수 있다. 완전 오픈 공개인 만큼, 커뮤니티 파인튜닝과 벤치마크 재현이 빠르게 이어질 것이다.
